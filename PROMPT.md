# The one prompt

The whole game — and the video about building it — comes from exactly one
prompt. The video shows the prompt, the agent writing the code, and the
finished game running.

> Build a tiny browser game in one HTML file: NEON DODGE — fly a little
> neon ship with arrow keys or mouse, dodge falling meteors, collect
> glowing stars for points, 3 lives, speed ramps up as your score climbs,
> bright neon on dark space, instant restart with R, and a demo autopilot
> so anyone can watch it play itself.

Everything in `game.html` — the ship, the meteors, the stars, the autopilot,
the score — comes from that one prompt. Open `game.html` in any browser to
play it: arrows / mouse to fly, R to restart, P to pause.
